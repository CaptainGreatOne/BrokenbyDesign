Create the `chaos-controller/` directory at the project root.

**1. Create `chaos-controller/package.json`:**
```json
{
  "name": "chaos-controller",
  "version": "1.0.0",
  "description": "Central chaos engineering controller for orchestrating failures across services",
  "main": "src/server.js",
  "scripts": {
    "start": "node src/server.js"
  },
  "dependencies": {
    "express": "^4.18.0"
  },
  "engines": {
    "node": ">=20.0.0"
  }
}
```

Only express is needed — Node.js 20 has native `fetch` for HTTP calls to services.

**2. Create `chaos-controller/src/services.js`:**

Service registry mapping service names to their chaos endpoint base URLs:
```javascript
const SERVICE_TARGETS = {
  'web-gateway': { url: 'http://web-gateway:3000', chaosPath: '/chaos' },
  'order-api': { url: 'http://order-api:8000', chaosPath: '/chaos' },
  'fulfillment-worker': { url: 'http://fulfillment-worker:2112', chaosPath: '/chaos' }
};
```

Export helper functions:

**`async function enableChaos(service, scenario, severity, params = {}, durationSeconds = null)`**
- If `service === 'all'`, call enableChaos for each service in SERVICE_TARGETS and return aggregated results
- Otherwise, POST to `${SERVICE_TARGETS[service].url}${SERVICE_TARGETS[service].chaosPath}/enable` with JSON body `{ scenario, severity, params, duration_seconds: durationSeconds }`. Only include `duration_seconds` in the body if it is not null (to preserve default toggle behavior on services that receive it).
- Return `{ service, status: 'enabled', response: ..., duration_seconds: durationSeconds }` on success
- Return `{ service, status: 'error', error: ... }` on failure (don't throw — allow partial failures when targeting 'all')

**`async function disableChaos(service, scenario)`**
- If `service === 'all'`, iterate all services
- POST to `.../chaos/disable` with `{ scenario }`
- Return result

**`async function resetChaos(service)`**
- If `service === 'all'`, iterate all services
- POST to `.../chaos/reset`
- Return result

**`async function getStatus(service)`**
- If `service === 'all'`, GET status from all services and return aggregated object
- GET from `.../chaos/status`
- Return result

Use `fetch()` with error handling (try/catch per service). Set timeout of 5 seconds for each call. Handle unreachable services gracefully (return error status, don't crash).

Export: `{ enableChaos, disableChaos, resetChaos, getStatus, SERVICE_TARGETS }`

**3. Create `chaos-controller/src/server.js`:**

Express server on port 9095 (configurable via PORT env var).

**REST API endpoints:**

**POST /api/chaos/enable** — Enable chaos on a service
Request body: `{ "service": "web-gateway|order-api|fulfillment-worker|all", "scenario": "latency|errors|crash|memory|disk", "severity": "mild|severe", "params": { ... optional }, "duration_seconds": <optional number> }`
- Validate service and scenario
- Extract `duration_seconds` from request body (may be null/undefined)
- Call `services.enableChaos(service, scenario, severity, params, durationSeconds)`
- Return 200 with results (including duration_seconds if provided)

**POST /api/chaos/disable** — Disable a specific chaos scenario
Request body: `{ "service": "...|all", "scenario": "..." }`
- Call `services.disableChaos(service, scenario)`
- Return 200

**POST /api/chaos/reset** — Reset all chaos
Request body: `{ "service": "...|all" }` (default: "all" if omitted)
- Call `services.resetChaos(service)`
- Return 200

**GET /api/chaos/status** — Get chaos status
Query param: `?service=...` (default: "all")
- Call `services.getStatus(service)`
- Return 200 with status

**GET /api/services** — List available target services
- Return SERVICE_TARGETS keys with their URLs

**Static file serving:**
Serve `/ui` from the `ui.html` file (or serve it at `/` for convenience). Use:
```javascript
const path = require('path');
app.get('/', (req, res) => {
  res.sendFile(path.join(__dirname, 'ui.html'));
});
```

**Health endpoint:**
```javascript
app.get('/health', (req, res) => {
  res.json({ status: 'healthy', service: 'chaos-controller' });
});
```

Add request logging to console for all API calls.

**1. Create `chaos-controller/src/ui.html`:**

A single-page HTML file with embedded CSS and JavaScript (no build tools needed). The UI provides:

**Layout:**
- Header: "Chaos Controller" with a "Reset All" button
- Status panel: Shows current chaos state for each service (refreshes every 5 seconds)
- Control panel: Form to trigger chaos scenarios

**Status Panel:**
- Three columns (one per service: web-gateway, order-api, fulfillment-worker)
- Each column shows active scenarios with severity level
- Color coding: green = no chaos active, yellow = mild chaos, red = severe chaos
- Auto-refreshes via `fetch('/api/chaos/status')` every 5 seconds

**Control Panel:**
- Dropdown: Select service (web-gateway, order-api, fulfillment-worker, all)
- Dropdown: Select scenario (latency, errors, crash, memory, disk)
- Radio buttons: Severity (mild, severe)
- "Enable" button: POSTs to `/api/chaos/enable`
- "Disable" button: POSTs to `/api/chaos/disable`
- Result display area showing API response

**Styling:**
- Clean, minimal CSS. Dark background (#1a1a2e) with light text for a "control panel" aesthetic
- Use monospace font for status display
- Cards for each service with border color indicating chaos status
- Responsive layout that works on a single monitor

**JavaScript:**
- `fetchStatus()` — GET /api/chaos/status?service=all, update status cards
- `enableChaos()` — POST /api/chaos/enable with form values
- `disableChaos()` — POST /api/chaos/disable with form values
- `resetAll()` — POST /api/chaos/reset with service=all
- `setInterval(fetchStatus, 5000)` for auto-refresh
- All API calls use `fetch()` with error handling

Keep the entire UI in a single HTML file (embedded `<style>` and `<script>` tags). This keeps the build simple and avoids any frontend tooling.

**2. Create `chaos-controller/Dockerfile`:**
```dockerfile
FROM node:20-alpine

# Install wget for health checks
RUN apk add --no-cache wget

WORKDIR /app

# Copy package files
COPY package.json package-lock.json* ./

# Install production dependencies
RUN npm install --production

# Copy source
COPY src/ ./src/

# Expose HTTP port
EXPOSE 9095

# Health check
HEALTHCHECK --interval=10s --timeout=3s --retries=3 \
  CMD wget -qO- http://localhost:9095/health || exit 1

CMD ["node", "src/server.js"]
```
